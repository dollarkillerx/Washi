# Washi 0.1.2

- **macOS:** updating no longer breaks the app's code signature. The app used to ship hundreds of .NET files whose
  signatures macOS keeps in extended file attributes, and the update package dropped them. Washi.app and washi-mcp
  are now single files, so everything in the app is signed inside the file itself. An app that already updated to
  0.1.1 gets a correctly signed app again with this update.
- Washi updates itself to this version (Settings → About → Check for updates, then Restart to update).
