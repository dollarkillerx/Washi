# Washi 0.1.0

The first packaged release of Washi, the open-source PDF toolkit. Pre-alpha: expect rough edges.

- **Forms.** Washi finds the boxes on flat PDF forms and makes them fillable. You can also fill forms that already
  have fields, right in the editor, including ones protected against changes that still allow filling in.
- **Editing.** Edit text, images and links; add headers, footers and watermarks; erase printed text for real.
- **Pages.** Organize, combine and split pages.
- **Review.** Comment, and compare two versions.
- **Protect.** Passwords, certificate encryption, redaction, and removing hidden information.
- **Output.** Compress; OCR (Apple Vision, Tesseract or an AI model); PDF/A; page labels, attachments and layers;
  form data.
- **Signatures.** Ink signatures, and digital signatures with long-term validation.
- **AI.** Built-in AI (Claude, GPT, DeepSeek or a local model), an AI assistant, and an MCP server for AI agents.
- **Languages.** English, 日本語, 简体中文, 繁體中文, 한국어, Français, Deutsch.
- **Updates.** Washi checks for updates itself (Settings → About) and installs them when you restart it.

macOS: Apple silicon, signed and notarized. Windows: x64, not code-signed yet. SmartScreen asks on the first run
(More info → Run anyway). On Windows, AI keys are read from environment variables (for example `ANTHROPIC_API_KEY`).
